# fornax_labextension

[![Github Actions Status](https://github.com/nasa-fornax/fornax-labextension/workflows/Build/badge.svg)](https://github.com/nasa-fornax/fornax-labextension/actions/workflows/build.yml)

A JupyterLab extension for Fornax

## Requirements

- JupyterLab >= 4.0.0

## Install

To install the extension, execute:

```bash
pip install fornax_labextension
```

## Uninstall

To remove the extension, execute:

```bash
pip uninstall fornax_labextension
```
